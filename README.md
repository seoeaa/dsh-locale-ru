# dsh-locale-ru — русский интерфейс для DeepSeek Harness

Кастомный плагин локали, добавляющий полноценную **русскую локаль** в веб-интерфейс [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh).

## Возможности

- **Полный перевод словарного интерфейса**: 26 namespace, ~690 строк — меню, настройки, чат (composer, сообщения, статусы, изображения), модели, плагины, пресеты агентов, субагенты и т.д.
- **Автоматически** включает русский, если браузер предпочитает русский язык.
- Переключатель **«Русский»** в *Settings → General → Language* (запоминается в localStorage браузера).
- **Переживает обновления dsh**: живёт в профиле (`~/.dsh/profiles/web/`), не трогает код фреймворка.

## Установка

Требуется: DeepSeek Harness, профиль `web` (путь `~/.dsh/profiles/web/`).

```bash
# 1. Склонировать плагин в папку плагинов профиля
git clone https://github.com/seoeaa/dsh-locale-ru.git ~/.dsh/profiles/web/plugins/dsh-locale-ru

# 2. Зарегистрировать плагин (добавит его в зависимости и бандлы профиля)
cd ~/.dsh/profiles/web
dsh plugin --profile web add file:./plugins/dsh-locale-ru

# 3. Перезапустить dsh web и обновить страницу (Ctrl+R)
```

После перезапуска:

- если браузер предпочитает русский — интерфейс станет русским автоматически;
- иначе выберите **Settings → General → Language → Русский** (выбор сохраняется в localStorage браузера).

## Обновление

```bash
cd ~/.dsh/profiles/web/plugins/dsh-locale-ru && git pull
cd ~/.dsh/profiles/web
pnpm add "file:./plugins/dsh-locale-ru"
# затем перезапустить dsh web
```

## Как это работает

dsh построен на [Cordis](https://github.com/cordiverse/cordis): веб-интерфейс локализуется плагином `@deepseek-ai/dsh-client-locale` через реестр словарей (`register(ns, { zh, en })`). Данный плагин:

1. регистрирует **русские словари** для всех namespace интерфейса (недостающие ключи фолбэчатся на английский);
2. добавляет `ru` в список языков (выпадающий список в настройках);
3. хранит выбор **локально в браузере** (localStorage) — серверная схема настроек принимает только `zh`/`en`, поэтому выбор `ru` не пишется в `settings.yaml`.

## Ограничения

- Текст, зашитый в код плагинов напрямую (не через словари), остаётся английским — это касается и штатных `zh`/`en`.
- Выбор языка хранится в браузере, а не в `settings.yaml`.
