# dsh-locale-ru — русский интерфейс для DeepSeek Harness

Кастомный плагин локали, добавляющий полноценную **русскую локаль** в веб-интерфейс
[DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (dsh).

## Возможности

- **Полный перевод словарного интерфейса**: 42 namespace, 1257 строк — чат и траектория,
  настройки (модели, плагины, разрешения, пресеты агентов, оформление), боковые панели,
  файлы, фоновые задачи, расписание, субагенты, навыки, обратная связь.
- **Публичный API локали**: плагин только регистрирует язык и словари
  (`addLanguage` + `register`), без вмешательства во внутренности dsh — поэтому
  обновления dsh его не ломают.
- **Автоматически** включает русский, если браузер предпочитает русский язык.
- Переключатель **«Русский»** в *Settings → General → Language*.
- Выбор языка **сохраняется в `~/.dsh/settings.yaml`** (`locale.preference`) силами самого dsh
  и действует во всех браузерах.
- Если ключа нет в переводе, интерфейс показывает английский текст — частичный перевод безопасен.
- **Переживает обновления dsh**: живёт в профиле (`~/.dsh/profiles/web/`), не трогает код фреймворка.

## Совместимость

- DeepSeek Harness **0.1.2-rc.1 и новее** (проверено на 0.1.5-rc.1 / 0.1.5-rc.2, а также 0.1.2-rc.1).
- Требуется сервис локали `@deepseek-ai/dsh-client-locale` — он входит в поставку dsh.
- Интерфейсы сторонних плагинов (например `dsh-better-sidebar`, `dsh-cron`, `dsh-mcp-panel`)
  в этот плагин не входят: их собственные словари остаются английскими. Добавить их можно
  тем же способом — отдельными namespace.

## Установка

```bash
# 1. Клонировать плагин в папку плагинов профиля
git clone https://github.com/seoeaa/dsh-locale-ru.git ~/.dsh/profiles/web/plugins/dsh-locale-ru

# 2. Зарегистрировать плагин (добавит его в зависимости и бандлы профиля).
#    Именно link: — тогда профиль использует сам клон, а не его копию:
#    `dsh plugin add file:...` копирует файлы в node_modules, и после
#    `git pull` харнесс продолжает отдавать старую копию.
cd ~/.dsh/profiles/web
dsh plugin --profile web add link:./plugins/dsh-locale-ru

# 3. Перезапустить dsh web и обновить страницу (Ctrl+R)
```

После перезапуска:

- если браузер предпочитает русский — интерфейс станет русским автоматически;
- иначе выберите **Settings → General → Language → Русский** (выбор сохранится в `settings.yaml`).

## Обновление

```bash
cd ~/.dsh/profiles/web/plugins/dsh-locale-ru && git pull
# затем перезапустить dsh web (клиентский бандл пересобирается сам)
```

Если плагин ставился старой командой `add file:...`, в `node_modules` профиля лежит копия,
и обновления в неё не попадают. Переведите установку на симлинк один раз:

```bash
cd ~/.dsh/profiles/web
rm -rf node_modules/@dsh-local/locale-ru
dsh plugin --profile web add link:./plugins/dsh-locale-ru
# затем перезапустить dsh web
```

## Как это работает

Интерфейс dsh локализуется плагином `@deepseek-ai/dsh-client-locale` через реестр словарей.
Публичный API сервиса `ctx.locale` позволяет плагину добавить язык целиком:

```js
exports.inject = ['locale']

exports.apply = function (ctx) {
  ctx.effect(() => ctx.locale.addLanguage({ id: 'ru', label: 'Русский', fallback: 'en' }))
  ctx.effect(() => ctx.locale.register('common', 'ru', { cancel: 'Отмена' }))
}
```

Этот репозиторий делает то же самое для 42 namespace интерфейса:

1. регистрирует язык `ru` с фолбэком на `en` — он появляется в списке языков,
   а активная локаль пересчитывается автоматически (настройки → браузер → английский);
2. регистрирует русские словари по каждому namespace; поиск идёт по цепочке `ru → en`,
   поэтому недостающий ключ показывает английский текст;
3. при выгрузке плагина снимает язык и словари — интерфейс возвращается к прежнему языку.

Выбор языка хранит сам dsh в `locale.preference`; плагин только регистрирует язык.
Подробности — в [docs/how-it-works.md](docs/how-it-works.md).

## Проверка и обновление перевода

Служебные скрипты работают без браузера и без запуска dsh: они загружают модули
установленного dsh в песочнице.

```bash
npm run verify   # плагин работает на настоящем сервисе локали dsh (20 проверок)
npm run check    # полнота перевода: 42/42 namespace, 1257/1257 строк, 0 расхождений
npm test          # обе проверки
```

Когда выходит новая версия dsh и в интерфейсе появляются английские строки:

```bash
npm run check     # покажет новые ключи (missing) и исчезнувшие (stale)
# перевести новые ключи в dsh/client.js, удалить stale
npm test
```

## Ограничения

- Текст, зашитый в код плагинов напрямую (не через словари), остаётся английским — это касается и штатных `zh`/`en`.
- Словари сторонних плагинов не входят в набор namespace этого репозитория.
- Русский не имеет формы множественного числа в словарях dsh (есть только `one`/`other`), поэтому
  счётчики сформулированы так, чтобы читаться при любом числе («Все файлы (12)», «{value} мин»).
